# myproj

Личное веб-приложение для одного пользователя: **Заметки**, **Дневник** и **Календарь** в одном интерфейсе.

## Стек

- Чистый HTML/CSS/JS без фреймворков и сборщиков — нативные ES-модули (`<script type="module">`)
- Данные сейчас хранятся в `localStorage` браузера. Слой хранения (`src/data/storageAdapter.js`) отделён от остального кода — позже можно подключить Supabase, реализовав тот же контракт, без переписывания сервисов и UI
- Деплой в будущем — Netlify (статика, сборка не нужна)

## Модули

- **Заметки** — папки (вложенные), теги, полнотекстовый поиск (везде / в папке / в заметке), режимы «писатель» (редактирование) и «читатель» (просмотр + выделение текста), wiki-ссылки между заметками (`[[id|текст]]`) с backlinks
- **Дневник** — одна запись на дату, редактируется в любой момент
- **Календарь** — месячная сетка, дни с записями дневника отмечены маркером, клик по дате открывает/создаёт запись за этот день

## Разработка

ES-модули не грузятся напрямую из `file://` (ограничение CORS браузеров), поэтому нужен локальный статический сервер:

```bash
npm run dev
```

Скрипт поднимает `npx serve` на `http://localhost:5173`. Альтернатива без Node.js — любой другой статический сервер (например, расширение VS Code Live Server) или `python -m http.server`, указав корень проекта.

## Структура проекта

```
index.html            # разметка-скелет, подключает стили и src/app.js
src/
  app.js               # hash-роутер (#/notes, #/diary, #/diary/YYYY-MM-DD, #/calendar)
  data/                # модели + слой хранения (контракт + localStorage-адаптер)
  services/            # бизнес-логика поверх слоя хранения (заметки, дневник, календарь, поиск, ссылки)
  modules/             # UI трёх модулей (notes, diary, calendar)
  utils/               # общие хелперы (DOM, даты)
styles/                # main.css + по файлу на модуль
```
