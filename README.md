# myproj

Личное веб-приложение для одного пользователя: **Задачи**, **Документы** и **Календарь** в одном интерфейсе. Desktop-приоритет.

## Стек

- Чистый HTML/CSS/JS без фреймворков и сборщиков — нативные ES-модули (`<script type="module">`)
- Данные хранятся в `localStorage` браузера. Слой хранения (`src/data/storageAdapter.js`) отделён от остального кода — позже можно подключить Supabase, реализовав тот же контракт, без переписывания сервисов и UI
- Деплой в будущем — Netlify (статика, сборка не нужна)

## Модули

**Главная** — четыре кружка на светлом фоне, от каждого идёт тонкая линия к центру экрана. Позиции слегка случайны при каждой загрузке, но общая схема по кругу сохраняется.

**Задачи** — папки, список заметок, редактор. Минимальный набор форматирования: жирный, подчёркивание, цвет текста, заливка, маркированный список, to-do с чекбоксами.

**Документы** — те же самые данные, что в Задачах (общий пул папок и заметок; создал в одном разделе — видно в другом). Отличается только тулбаром: добавлены зачёркивание, заголовки H1/H2, выравнивание, нумерованный список, таблицы и переключатель режима страницы.

Общее для обоих разделов: обе панели (папки и список) сворачиваются, свёрнутые схлопываются в тонкую полоску у левого края. ПКМ по папке или заметке — создать, переименовать на месте, удалить, добавить в избранное. Крестик мгновенного удаления показывается только у пустых. Drag-and-drop меняет порядок, кладёт заметку в папку и добавляет в избранное. Режим отображения — «сплошной лист» или «постранично»: в Документах кнопкой в тулбаре, в Задачах — через ПКМ внутри открытой заметки.

**Календарь** — сначала 12 месяцев кружками, затем дни месяца кружками, клик по дню открывает панель записей снизу. Запись — заметка или to-do, с диапазоном времени «от-до» и цветным тегом (теги создаются свои, с произвольным цветом). На кружке дня — точка цвета тега, а если записей несколько, их количество цифрой.

**AI** — кружок на главной есть, функционала пока нет: при наведении затемняется и показывает «Недоступно пока».

**Поиск** — полоска сверху по центру, на всех экранах. Ищет по названиям папок, названиям и тексту заметок, по записям календаря и их тегам; показывает до трёх совпадений на заметку с куском текста вокруг каждого. Клик по результату открывает нужное место и подсвечивает найденное слово. На главной поиск глобальный, внутри раздела — по разделу; Tab переключает область.

**Настройки** — шестерёнка в углу: язык интерфейса (английский по умолчанию, переключается на русский), обводка панелей, очистка данных.

## Разработка

ES-модули не грузятся напрямую из `file://` (ограничение CORS браузеров), поэтому нужен локальный статический сервер:

```bash
npm run dev
```

Скрипт поднимает `npx serve` на `http://localhost:5173` (`serve.json` отключает кэширование, чтобы правки подхватывались сразу). Альтернатива без Node.js — любой другой статический сервер, например расширение VS Code Live Server или `python -m http.server` из корня проекта.

Сборки, линтера и тестов нет — проверка изменений визуальная, в браузере.

## Структура проекта

```
index.html            # разметка-скелет, подключает стили и src/app.js
src/
  app.js               # hash-роутер (#/tasks, #/documents, #/calendar) + обработка Esc
  data/                # модели + слой хранения (контракт + localStorage-адаптер)
  services/            # бизнес-логика поверх слоя хранения
  modules/             # UI разделов; shared/ — общая панель, редактор, контекстное меню
  i18n/                # словарь переводов en/ru
  settings/            # панель настроек (язык, обводка, очистка данных)
  utils/               # DOM, даты, модалки, слои Esc
styles/                # main.css + по файлу на раздел
```

## Пока не реализовано

Отложено намеренно: ссылки между заметками, теги у заметок (есть только у записей календаря), режим «только чтение» для общего доступа, история изменений, трекер привычек и AI. Архитектура их не блокирует.
